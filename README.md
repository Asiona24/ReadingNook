# ReadingNook

A simple book's review Website where the user's can signup to write and share different opinions about all the book they've read and find new
ones that the others recommend!

## Technologies
Project is created with:
* PHP version: 8.1.2
* Bootstrap versione: 5.3.0
* Jquery version: 3.6.4
* FontAwesome: 5.0.8
* Postgresql
* VisCode with extensions: PHP Server, PHP IntelliSense
* Apache XAMPP

## Setup
The website uses a postgres DB (the file to create the table are inside the ReadingNookDB folder)
